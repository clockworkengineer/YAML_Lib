# Extending YAML_Lib Guide

`YAML_Lib` provides clean extension points via strategy interfaces and registries. This guide demonstrates how to extend the library with custom stringification formats, custom schemas, node factories, and stream sources.

---

## 1. Registering Custom Stringifiers (`StringifierFactory`)

To add a custom output format (for example, TOML or CSV), implement `IStringify` and register a factory creator with `StringifierFactory`:

```cpp
#include "YAML.hpp"
#include "YAML_Writer.hpp"
#include "implementation/common/YAML_StringifierFactory.hpp"
#include <iostream>

class CustomTOMLStringify : public YAML_Lib::IStringify {
public:
  void stringify(const YAML_Lib::Node &yNode,
                 YAML_Lib::IDestination &destination,
                 unsigned long indent) const override {
    // Custom TOML serialization logic
    destination.add("# Generated by CustomTOMLStringify\n");
    // Format node contents into destination...
  }
};

// Register creator strategy by format name
void registerCustomFormat() {
  YAML_Lib::StringifierFactory::instance().registerCreator(
      "TOML", []() { return std::make_unique<CustomTOMLStringify>(); });
}

int main() {
  registerCustomFormat();
  auto yaml = YAML_Lib::YAML::load("key: value");
  std::string tomlOutput = yaml->dump("TOML");
  std::cout << tomlOutput << std::endl;
}
```

## 2. Creating Custom Schemas (`ISchema`)

To customize how scalar strings are coerced into node types (e.g. implementing JSON Schema or Failsafe Schema), implement `ISchema`:

```cpp
#include "YAML.hpp"
#include "YAML_Reader.hpp"
#include "interface/ISchema.hpp"
#include "implementation/parser/Default_Parser.hpp"
#include "implementation/translator/Default_Translator.hpp"
#include "implementation/io/YAML_Sources.hpp"

class FailsafeSchema : public YAML_Lib::ISchema {
public:
  [[nodiscard]] YAML_Lib::Node resolveScalar(std::string_view scalarText,
                                             bool /*isQuoted*/) const override {
    // Failsafe Schema resolves all scalars as Strings regardless of content
    return YAML_Lib::Node::make<YAML_Lib::String>(scalarText);
  }

  [[nodiscard]] YAML_Lib::Node resolveTag(std::string_view /*tagHandle*/,
                                          std::string_view /*tagSuffix*/,
                                          YAML_Lib::Node node) const override {
    return node;
  }
};

int main() {
  auto parser = std::make_unique<YAML_Lib::Default_Parser>(
      std::make_unique<YAML_Lib::Default_Translator>());
  parser->setSchema(std::make_unique<FailsafeSchema>());

  YAML_Lib::BufferSource source("12345");
  auto nodes = parser->parse(source);
  // nodes[0] is resolved as String("12345") rather than Number
}
```

## 3. Custom Node Creation Strategy (`INodeFactory`)

To intercept or customize node allocation/construction, implement `INodeFactory`:

```cpp
#include "interface/INodeFactory.hpp"
#include "implementation/common/YAML_DefaultNodeFactory.hpp"
#include <iostream>

class LoggingNodeFactory : public YAML_Lib::DefaultNodeFactory {
public:
  [[nodiscard]] YAML_Lib::Node createString(std::string_view value) const override {
    std::cout << "[Factory] Allocating String node: " << value << "\n";
    return YAML_Lib::DefaultNodeFactory::createString(value);
  }
};
```

## 4. Custom Input Sources (`ISource`)

To parse YAML directly from custom memory buffers or network streams, implement `ISource`:

```cpp
#include "interface/ISource.hpp"
#include <string_view>
#include <stack>

class CustomMemorySource : public YAML_Lib::ISource {
public:
  explicit CustomMemorySource(std::string_view data) : data_(data) {}

  [[nodiscard]] char current() const override {
    return more() ? data_[pos_] : '\0';
  }

  void next() override {
    if (pos_ < data_.size()) {
      ++pos_;
    }
  }

  [[nodiscard]] bool more() const override {
    return pos_ < data_.size();
  }

  void reset() override {
    pos_ = 0;
    while (!savedPositions_.empty()) {
      savedPositions_.pop();
    }
  }

  [[nodiscard]] std::size_t position() override {
    return pos_;
  }

  void save() override {
    savedPositions_.push(pos_);
  }

  void restore() override {
    if (!savedPositions_.empty()) {
      pos_ = savedPositions_.top();
      savedPositions_.pop();
    }
  }

  void discardSave() override {
    if (!savedPositions_.empty()) {
      savedPositions_.pop();
    }
  }

private:
  std::string_view data_;
  std::size_t pos_{0};
  std::stack<std::size_t> savedPositions_;
};
```
